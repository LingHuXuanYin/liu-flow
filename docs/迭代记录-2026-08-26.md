## 四、本期调测经验

### 调试经验

- **问题**：主流程登录 NPE `UserDto.getUid()` on null reference
  **解决**：CloudBase `/signin` 实际响应字段是 `sub`，不是嵌套 `user.uid`。V0.1.0 误读假设导致 NPE。两步修：短期把 `UserDto` 字段改 nullable；长期砍掉整套 `AuthRepository` / `AuthSession` / `User`，按文档示范用 `Map<String, Any>` 直接读 `sub`。

- **问题**：CloudBase `/auth/v1/verification` 返回 400 `invalid value for enum type: "NON_USER"`
  **解决**：用 curl 直接打目标端 6 个常见 enum 值（NON_USER / EMAIL / EMAIL_SIGNUP / SIGNUP / VERIFY_EMAIL / LOGIN），全部 400，仅 `ANY` 返回 200。文档示范的 `"NON_USER"` 在当前目标端已过时，临时用 `"ANY"` 跑通注册。注释里记下证据，方便后续环境更新时回退。

- **问题**：注册流程跳到 `AuthRoutes.SignupVerify` 后立刻被 `popBackStack` 弹回
  **解决**：新路由的 `viewModel(factory = factory)` 拿的是新 `NavBackStackEntry` 的新实例，`verificationId` / `pendingEmail` / `step` 状态全丢，跳过去 `step` 是 `EmailForm`（不是 `CodeSent`）→ 立刻 `popBackStack`。改用单页 + `_step` StateFlow 切 UI，不跳路由。

- **问题**：「我的」页底部没看到登出按钮
  **解决**：`MeScreen` 的 `onSignOut` 默认参数是 `{}` 空函数，`FlowNavHost` 里也没传，点了没反应。改 MeScreen 删掉 `onSignOut` 参数，直接调 `viewModel.signOut()`。又发现登出按钮显示判定用 `viewModel.email.isNotBlank()`，但 CloudBase /signin 响应里 `email` 是可选的，登录后可能没 email 字段。改用 `isLoggedIn: StateFlow<Boolean>`（看本地 token 存在）判定。

- **问题**：`Modifier.align(Alignment.CenterHorizontally)` 编译报 `Unresolved reference 'align'`
  **解决**：`align` 是 `ColumnScope` / `RowScope` 扩展方法，在顶层 Composable（`EmailFormStep` / `CodeSentStep`）里不可用。改用 `Modifier.fillMaxWidth().wrapContentWidth(Alignment.CenterHorizontally)`，效果一样但不需要 Scope 上下文。

- **问题**：`wrapContentWidth` 编译报 `Unresolved reference 'wrapContentWidth'`
  **解决**：补 `import androidx.compose.foundation.layout.wrapContentWidth`。

- **问题**：删了 `AuthError` 后 `ApiResult.Failure.error: AuthError` 引用全部编译失败
  **解决**：把 `ApiResult.Failure` 字段从 `error: AuthError` 改成 `message: String`（直接用接口响应 message），批量替换 DebugViewModel 10 处 `r.error.message` → `r.message`。
